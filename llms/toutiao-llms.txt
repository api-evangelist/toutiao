# Toutiao (今日头条)

> Toutiao is ByteDance's AI-driven content recommendation platform, launched in 2012,
> aggregating news, articles, short video and micro-posts into a personalized feed for
> readers in China. Its developer surface is a Toutiao account OAuth 2.0 and user-profile
> API served from open.snssdk.com, plus a console-gated content-publishing capability.

## What an agent should know first

- There is NO OpenAPI, AsyncAPI, GraphQL schema, MCP server or A2A agent card for Toutiao.
  Every discovery path was probed on 2026-08-05 and every one missed. Do not expect a
  machine-readable contract.
- The API returns HTTP 200 for application errors. Branch on the JSON body
  (`message == "error"`, `data.error_code`), never on the transport status.
- All documentation and all error messages are Chinese-only (zh-CN).
- Credentials require an approved application in the open-platform console; review is
  documented as 1-3 business days. There is no self-serve key.

## APIs

- [Toutiao Open API (OAuth + User Profile)](https://open.douyin.com/platform/resource/docs/develop/permission/toutiao-or-xigua/OAuth2.0/):
  Base URL https://open.snssdk.com. OAuth 2.0 authorization-code flow returning open_id,
  nickname and avatar. Access token 15 days, refresh token 30 days.

## Endpoints (confirmed live by differential probe, 2026-08-05)

- `GET https://open.snssdk.com/oauth/authorize/` — start the authorization-code flow
- `GET https://open.snssdk.com/oauth/access_token/` — exchange auth_code for an access token
- `GET https://open.snssdk.com/oauth/refresh_token/` — refresh an expired access token
- `GET https://open.snssdk.com/oauth/renew_refresh_token/` — renew the refresh token
- `POST https://open.snssdk.com/oauth/userinfo/` — authorized user's public profile
- `GET https://open.snssdk.com/oauth/client_token/` — application-level (client) token
